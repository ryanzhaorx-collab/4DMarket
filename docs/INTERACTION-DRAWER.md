# 「抽屉」空间进入交互设计

> 目标：点击大楼 → 楼层像抽屉一样拉开 → 房间盒子滑出 → 俯视 → 穿墙落到落地窗前。
> 感知上不是"页面跳转"，而是"空间被拉开"。

---

## 1. 先看我们现在的加载链路

| 环节 | 现状 | 对"抽屉"的支持度 |
| --- | --- | --- |
| 资产 | 单场景 3DGS 分块（9 块 × 2 LOD）+ 倾斜摄影瓦片 | ❌ **没有"楼 / 层 / 房"的层级**，只有空间块 |
| 加载 | manifest 驱动；LOD0 先出（进度 50% 收起 loader），LOD1 逐块替换并交叉淡入 | ✅ 渐进有，但粒度是"块"，不是"层" |
| 入场 | `resolve` 粉尘凝聚 + 相机推进 | ✅ 可复用为抽屉第一段的"凝聚感" |
| 镜头 | 原先只有单段 `flyTo` | ✅ 本轮补了**多段相机时间轴** |
| 交互 | 拖拽阻尼 / 双击复位 / 空闲自转 / 动态缩放 | ✅ 够用 |
| 反馈 | 无声音、无触觉 | ✅ 本轮补了合成音效 + 震动 |
| 室内 | 无资产，用底部浮层代替 | ❌ 抽屉第三段缺资产 |

**结论：渲染和镜头不是瓶颈，缺的是"分层资产"和"分层加载"。**
抽屉动效本质是"把一栋楼拆成可独立操作的层"，这需要建模阶段就分层导出，而不是渲染阶段硬切。

---

## 2. 状态机

```
S0 探索（航拍）
 │ 点击楼体
 ▼
S1 锚定（楼体高亮、四周压暗、镜头拉远成微缩模型）
 │
 ▼
S2 抽屉（目标楼层平移错开，其余层退后/淡出）
 │
 ▼
S3 房间盒子（玻璃盒滑出，带阻尼回弹）
 │
 ▼
S4 穿墙（俯视 → 相机下降越过墙 → 落地窗前平视）
 │
 ▼
S5 室内（环视 + 轻交互；可返回 S3/S0）
```

任何一段都可被用户手势打断：拖拽 = 取消并停在当前态（不做"强制播放完"）。

---

## 3. 时间轴

总时长 **3.4s**（可被打断），每一段都有明确的"起—收"。

| t (s) | 阶段 | 画面 | 镜头 | 声音 / 触觉 |
| --- | --- | --- | --- | --- |
| 0 | 点击 | 楼体描边亮起，场景四周亮度 -35% | 不动 | 触觉 8ms |
| 0.10–0.70 | 宏观锚定 | 楼缩成居中微缩模型，慢转 5° | 拉远、降 pitch，FOV 55→51 | whoosh 起 |
| 0.70–1.35 | 抽屉拉出 | 目标层（8F）平移 2.4m，相邻层退后 0.6m 并淡到 45% | 微推 + yaw −6° | 滑动声（低频持续） |
| 1.35–2.10 | 房间滑出 | 玻璃盒从楼层滑出，末端 0.12m 回弹 | 环绕到房间正上方 | 卡扣声 + 触觉 12ms |
| 2.10–3.30 | 穿墙 | 盒子展成无顶俯视 → 越过墙 → 落到窗前 | pitch 1.2→0.12，距离 1.6→0.9，FOV 48→38 | 海浪环境音在 2.6s 渐入 |
| 3.30 | 落位 | 室内稳定，第一个可点物体呼吸高亮 | 停止 | 触觉 15ms |

> AI 那份建议里"穿墙控制在 1.5s 左右、FOV 保持稳定"是对的。这里的处理是：**FOV 单向下行**（55→38），全程不回弹——单向变化不会产生"变焦拉扯感"。

---

## 4. 镜头语言（防晕的三条硬规矩）

1. **单调**：高度单调下降、FOV 单调收窄，不允许中途反向。
2. **留呼吸**：相邻两段之间插 100ms 的"停一拍"（两个值相同的关键帧），这是"高级感"的来源——匀速直线运动会显得廉价。
3. **不横滚**：全程 `roll = 0`，不做"无人机倾斜"。

缓动选择：

| 段 | 缓动 | 理由 |
| --- | --- | --- |
| 宏观锚定 | `outCubic` | 先快后慢，快速建立"这是模型"的认知 |
| 抽屉拉出 | `outBack`（轻微） | 末端 0.12m 过冲再回弹 = 机械阻尼感 |
| 环绕 | `inOutCubic` | 两端软，中间快，像转盘 |
| 穿墙 | `outExpo` | 收得极狠，落位干净利落 |

## 5. 资产分层（能不能做成的关键）

需要的三层，各自独立 LOD、独立包围盒：

```
scene/
  building/        楼体（远景 LOD0-2，含屋顶穹顶）
  floor/f08/       单层切片（外墙 + 走廊，可独立平移）
  room/r270/       房间 3DGS（室内家具、窗、光线）
```

**抽屉效果的两种实现**：

| 方案 | 做法 | 成本 | 建议 |
| --- | --- | --- | --- |
| A 真分层 | 每层是独立 splat 块，用逐块 `transform` + `alpha` 动画 | 建模要分层导出 | 正式版 |
| B 伪分层 | 整楼一份点云，用裁剪平面/包围盒遮罩切出"层"，再整体平移 | 渲染改造成本低，边缘有锯齿 | MVP 验证动效 |

我们现在已经有 `LayerTransform`（平移/三轴旋转/缩放），扩成"逐块可动画"只差一个 per-tile 的 tween 队列——**建议先做 B 验证节奏，再做 A**。

## 6. 加载策略（三级 + 兜底）

| 资产 | 时机 | 要求 |
| --- | --- | --- |
| 楼体 LOD0 | 首屏常驻 | 已有，点击瞬间能拉出 |
| 楼层切片 | 点击瞬间预取 | 命中缓存 <300ms 则无感；未命中则先拉抽屉再补层 |
| 房间 3DGS | 抽屉滑出的 0.9s 窗口内 | 首帧用 20% LOD，进入后 1.2s 内补到全量 |
| **兜底** | 1.2s 内房间没到 | 用一段**预渲染视频**接过穿墙段（AI 建议里的"取巧"，其实是标准做法） |

> 我们现在的 `resolve`（粉尘凝聚）刚好可以复用为"抽屉拉出时，新层从粉尘聚成实体"——同一个 shader 分支，改一下 `uScatter` 和触发时机即可。

## 7. 轻交互前置

进房后 0.8s，落地窗前 1.5m 处那个"发光鱿鱼丝"开始呼吸（透明 0.7↔1.0，2s 周期）。
第一眼必须有一个"可以点"的东西，否则用户会原地打转。

## 10. 本轮已经做了什么

| 能力 | 状态 |
| --- | --- |
| 多段相机时间轴（关键帧 + 分段缓动 + FOV 动画） | ✅ `src/engine/CameraTimeline.ts`，`Engine.playTimeline()` |
| 「进入」改成三段式运镜（锚定 → 环绕推进 → 压低穿透） | ✅ 2.2s，末段 FOV 55→46 |
| 合成音效（whoosh / 卡扣），零音频文件 | ✅ `src/ui/sfx.ts` |
| 触觉反馈 | ✅ 落位 12ms（Android 生效，iOS 静默） |
| 浮层在落位瞬间弹出（不等动画完全结束） | ✅ |
| 楼层剥离（方案 B） | ✅ 见下方 |
| 房间滑出 / 穿墙 | ❌ 缺房间资产，见第 5 节 |
| 室内 3DGS | ❌ 无资产 |

### 方案 B 的实际实现：拆分 + 自下而上浮出

| 时间 | 动作 | 实现 |
| --- | --- | --- |
| 0–1.1s | **楼体上下分开**：上半 +0.15h、下半 −0.12h，中间那层同时消隐 | `uSplit` + soft smoothstep |
| 0–1.0s | 镜头切到 3/4 固定机位（340m / pitch 0.3） | 相机时间轴 |
| 1.0–1.35s | **停一拍**，露着 60 多米高的空隙 | 两个相同关键帧 |
| 1.35–2.85s | **整层从楼体内部自下而上浮出**：起点在缝底以下 3m，升 40m 到缝中心 | 位置插值 + `outBack` |
| 同步 | **自下而上渐变显形**：显形前沿从楼板底面往上推，边缘 1.8m 渐变带 | 片元里按 `vLocalY` 裁剪 |

**为什么是"浮出"而不是"滑出"**：横向滑出在正面机位下会掉到缝外面去；
从内部升起、边升边显形，才有"嵌在楼体里被抽出来"的质感。

实现细节：

- 楼层在 `VirtualRoom` 里是独立 mesh，带 `uReveal`（0..1）和 `uRevealH`（层高）；
- 片元把 `alpha *= smoothstep(edge, edge + 1.8, 局部Y)`，`edge = uReveal * 层高 * 1.18`，
  所以是"从地板往天花板"一点点长出来；
- 透明度整体延后 18% 才开始升，避免在楼体内部就被看见。



## 12. 进入第二页（过场特效 + 直接切页）

点「进入」后**不做镜头推进**，只播一段过场特效，特效结束时页面已经换成第二页。

| 时间 | 动作 |
| --- | --- |
| 0ms | 白闪开始（径向 #FFF8F0 → 透明）+ 画布 20px 模糊、1.05 倍放大 + whoosh |
| 430ms | **特效峰值时瞬切**：相机直接落到室内机位、裙楼换成套间、第二页 UI 淡入 |
| 960ms | 特效结束，交还交互，落位轻震动一次 |

- 白闪：`radial-gradient` + `flashPulse 0.95s`，峰值不透明度 0.95
- 画布：`swingBlur 0.95s`（0 → 20px → 8px → 0），纯 CSS filter，不占渲染管线
- 第二页 UI：顶部「点亮东山 3/8」胶囊、左上返回、底部提示；首屏品牌/卡片淡出
- 返回：左上角 ‹ 恢复首屏（拆分收起、卡片还原、相机回默认机位）

**为什么不用飞行**：飞行会让用户以为还在同一个空间里操作；切页则明确"进入了一个新页面"，
也避免在 92m 的裙楼和 10m 的客房之间穿模。
