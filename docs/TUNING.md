# 怎么改动画效果（不用碰代码）

## 方式一：调参面板（推荐）

打开 **`http://127.0.0.1:5178/?engine=pc&tune=1`**，右下角出现面板：

| 滑杆 | 控制什么 | 默认 |
| --- | --- | --- |
| 分层间距 | 爆炸图每层错开多少米 | 16m |
| 分层时长 | 千层糕展开多久 | 1800ms |
| 抽屉推出距离 | 玻璃层沿视线推多远 | 92m |
| 抽屉时长 | 推出多慢 | 2400ms |
| 抽屉起始高度 | 出层位置（正数向上） | 8m |
| 入场显影时长 | 分界线扫过多慢 | 4200ms |
| 主机位距离 / 水平角 / 俯仰 | 第二拍镜头落点 | 590m / 0.98 / 0.2 |

- 拖动即时生效，**刷新后保留**（存 localStorage）
- **重播**：按当前参数重跑裂开→抽屉
- **复制配置**：把当前值复制成 JSON，贴给开发就能写死

## 方式二：URL 参数（少量开关）

| 参数 | 作用 |
| --- | --- |
| `?engine=pc` | 用 PlayCanvas 内核 |
| `?tune=1` | 打开调参面板 |
| `?debug=1` | 显示性能/调试信息 |
| `?budget=400000` | 点云预算（越大越清晰越慢） |

## 方式三：改代码（要提交时）

| 想改 | 文件 | 位置 |
| --- | --- | --- |
| 默认参数 | `src/ui/tune.ts` | `DEFAULT_TUNE` |
| 镜头关键帧 | `src/pc/boot.ts` | `openDrawer()` 里的 `playTimeline([...])` |
| 抽屉方向/顺序 | `src/pc/boot.ts` | `PUSH`、`showRoom(...)` |
| 分层位移算法 | `src/engine/pc/PcEngine.ts` | `onUpdate()` 里 `unfoldSpreadY` 段 |
| 显影特效参数 | `src/engine/pc/viewer/develop-effect.js` | `uBand / uStreak / uGlow` |

## 调完怎么固化

1. 面板里点「复制配置」→ 得到 JSON
2. 把 JSON 贴给开发（或自己改 `DEFAULT_TUNE`）
3. 清 localStorage 前记得先复制

## 原则

**能调的都做成参数，不要散落在代码里。** 新增动画时，先在 `TuneParams` 里加一个字段，
再做动画——这样以后永远不用为了改一个数去翻代码。
